## Design Context

### Users

A household — parents and kids, mostly **non-technical**. One person does a
one-time admin setup, then everyone gets a local account. Used on the family's
own home laptop (the Tauri **desktop** app) and phones (the Android app). It is
**local-first**: inference runs on a local Ollama, nothing is sent to a cloud
API, nothing leaves the machine. The jobs to be done: talk to a local assistant
to make tasks / find a document / build a small tool; drop a file in a watched
folder and have it classified; keep a shared sticky board; a family chat.

### Brand Personality

Warm · calm · handcrafted. "A well-loved paper notebook under afternoon light" —
tactile, unhurried, private, trustworthy. Never clinical, never flashy, never
enterprise-SaaS. Copy has a little editorial weight but stays plain-spoken.

### Aesthetic Direction

Refined minimalism, the "Notion — warm paper notebook" system.

- **Canvas** `#f6f5f4` (warm off-white, the signature). **Cards** `#ffffff`.
  Never invert. Never pure-white page background.
- **One** chromatic commitment: Notion Blue `#0075de` — the single filled
  button per screen, active nav, links. Everything else is ghost (`#e6f3fe`
  tint) or text. No second button colour in a view.
- **Hairline borders only** — `rgba(0,0,0,0.08)`, 1px. **No shadows on content
  cards.** The only shadows in the whole system: the sticky notes on the Board
  (they must read as physical paper — deliberate, contained exception) and the
  nav.
- Text is `#000` at stepped **alpha** (100 / 95 / 60 / 40 / 20), never a
  separate grey token for hierarchy. Body copy gets a warm-cast graphite
  (`#615d59`).
- Type: **Inter** for all UI. **Source Serif 4** only for rare editorial
  moments (never labels/nav). Negative tracking on display sizes; body normal.
- Shape: **12px** card radius, **8px** button radius, **4px** small, **9999px**
  pills. Nothing rectangular over 12px.
- Spacing on a **4px** base (4/8/12/16/20/24/28/32). Comfortable density, calm
  vertical rhythm.
- Motion: **200ms ease** for hovers/transitions; spring/bounce reserved for
  delight moments (character marks, the board). Respect `prefers-reduced-motion`.
- **Light theme only.** No dark mode. No gradients (flat fills only). No
  glassmorphism. No colored side-stripe accents.

### Design Principles

1. **The canvas is warm, the cards are white** — that contrast, plus accent
   card fills, does all the elevation work. Borders, not shadows.
2. **Colour is punctuation.** One blue action per screen; hue variety lives in
   card backgrounds, not controls.
3. **Hierarchy through alpha and weight**, not new colours or sizes.
4. **Calm over dense.** Generous spacing, one clear next action, quiet empty
   states that teach.
5. **Non-technical audience** — plain words, forgiving states, never expose
   jargon (ids, kinds, error stacks) in the primary path.

2. DEMO ACCOUNT  (required, and this is the hard part)
--------------------------------------------------------------------------------
A reviewer in Cupertino has nothing on their LAN advertising _familyagent._tcp,
so the app will sit on the "find a server" screen and the review will be
rejected under Guideline 2.1 (App Completeness) unless you give them a working
server to point at.

You must stand up ONE internet-reachable agent-core instance with a real HTTPS
certificate (a plain http:// public host needs an ATS exception Apple pushes
back on — NSAllowsLocalNetworking only covers local names, not a public host),
then provide:

    Server URL (for the app's "Enter address manually" field):
        https://<your-demo-host>
    Username:
        reviewer
    Password:
        <set a fixed password, put it here>

Seed that account with a few documents, events, notes and a routine so every tab
has content. Keep the host up for the whole review window and any resubmission.

Then, in "Notes" below, tell the reviewer exactly how to use it (see item 4).

Alternative (more work, but no server to keep alive): build a DEBUG-style demo
mode into a Release build that serves canned data with no network. Not currently
in the app.

4. NOTES  (free text — paste something like this)
--------------------------------------------------------------------------------
Family Agent is the iPhone companion to a self-hosted home server ("agent-core",
distributed as a free macOS app). The phone app is a pure client: it discovers
the server on the local network, or connects to a typed address.

For review, a hosted demo server is available:

  1. Launch the app. On the first screen, tap "Enter address manually" (or the
     manual-entry option on the discovery screen).
  2. Enter:  https://<your-demo-host>
  3. Sign in:  username "reviewer", password "<password>".
  4. You will land on Chat. Try: "What do I have coming up this week?" — replies
     are generated by a language model on the server and can take 30-120 seconds;
     this is expected for local inference.
  5. The menu button (top-left) opens the drawer to every other screen: Events,
     Documents, Messages, Board, Routines, Vault, Activity, Settings.

The app collects no data and contains no analytics or advertising SDK. All
content shown is on the demo server. Microphone / camera / photo prompts appear
only when you use voice input, document scanning, or a photo attachment.

App Transport Security is disabled (NSAllowsArbitraryLoads). The app only ever
connects to a Family Agent server the user runs on their own hardware and
supplies by hand — a private LAN address, or a Tailscale / VPN address in the
100.64.0.0/10 range that NSAllowsLocalNetworking does not cover. There is no
first-party or public endpoint and no HTTPS option for a user's home server.
The hosted demo above is HTTPS; arbitrary loads is for real users' local
servers, the same pattern as other self-hosted-server clients.
